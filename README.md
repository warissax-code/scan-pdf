# สแกนเอกสารเป็น PDF (ออฟไลน์ บน iPhone)

เว็บแอปสำหรับสแกนเอกสารเป็นไฟล์ PDF ที่ติดตั้งลงหน้าจอโฮมได้เหมือนแอปทั่วไป
ใช้อินเทอร์เน็ต **ครั้งเดียวตอนติดตั้ง** หลังจากนั้นใช้งานได้แม้เปิดโหมดเครื่องบิน
ภาพทุกภาพประมวลผลในเครื่อง ไม่มีการส่งรูปออกไปที่ไหน

## ความสามารถ
- **กล้องในแอปจับขอบกระดาษสด ๆ** — เห็นกรอบสีฟ้าตามขอบเอกสารตอนเล็ง เมื่อถือนิ่งกรอบจะเป็นสีเขียวแล้ว **ถ่ายให้อัตโนมัติ** เปลี่ยนหน้าแล้วถ่ายต่อได้เรื่อย ๆ (ปิดโหมดอัตโนมัติแล้วกดถ่ายเองก็ได้)
- เลือกรูปจากคลังรูปได้หลายรูปพร้อมกัน หรือใช้กล้องของระบบ (ปุ่ม 📷 มุมขวาบนในหน้ากล้อง)
- หาขอบกระดาษอัตโนมัติ ลากปรับมุมเองได้ (มีแว่นขยายช่วยตอนลาก) และดัดภาพที่ถ่ายเอียงให้เป็นหน้าตรง
- ฟิลเตอร์ 5 แบบ
  - **สีปกติ** (ค่าเริ่มต้น): แก้แสงให้กระดาษขาวขึ้นเล็กน้อย สีตามจริง
  - **สีคมชัด**: ลบเงาและสีแสงไฟ พื้นขาวสะอาด สีสด
  - **ขาวเทา**: เหมาะกับเอกสารตัวหนังสือ
  - **ขาวดำ**: เหมือนเครื่องสแกน ไฟล์เล็ก
  - **ภาพถ่าย**: ไม่ปรับแต่งภาพ
- หลายหน้าในไฟล์เดียว: ลากปุ่ม ≡ เพื่อเรียงลำดับ หมุน ลบ หรือแก้หน้าเดิมได้
- เลือกขนาดกระดาษ A4 / Letter / พอดีรูป และคุณภาพ เล็ก / กลาง / ชัดสุด
- บันทึกลงแอป "ไฟล์" หรือแชร์ไปที่ LINE / อีเมลผ่านเมนูแชร์ของ iPhone
- งานที่สแกนค้างไว้ไม่หาย แม้ปิดแอปไปแล้ว

## ติดตั้งบน iPhone
1. เปิดลิงก์ของแอปด้วย **Safari** (ต้องเป็น Safari)
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรชี้ขึ้น) แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** จากนั้นกด **เพิ่ม**
3. เปิดแอปจากไอคอน "สแกน PDF" บนหน้าจอโฮม 1 ครั้งตอนที่ยังต่อเน็ตอยู่ เพื่อให้แอปเก็บไฟล์ไว้ในเครื่อง
4. หลังจากนี้ใช้งานแบบออฟไลน์ได้ตลอด
5. ครั้งแรกที่กดถ่ายภาพ iPhone จะถามขออนุญาตใช้กล้อง ให้กด **อนุญาต** (แอปที่ติดตั้งบนหน้าจอโฮมอาจถามซ้ำเมื่อเปิดแอปใหม่ ซึ่งเป็นข้อจำกัดของ iOS)

## วิธีใช้
1. กด **📷 ถ่ายภาพ** แล้วเล็งกล้องให้เห็นกระดาษทั้งแผ่น (ครั้งแรกให้กดอนุญาตใช้กล้อง)
2. ถือนิ่ง ๆ จนกรอบเป็นสีเขียว แอปจะถ่ายให้เอง จากนั้นเปลี่ยนเป็นหน้าถัดไปได้เลย
3. ถ่ายครบแล้วกด **เสร็จ** — ถ้าหน้าไหนขอบไม่ตรง แตะที่หน้านั้นเพื่อลากมุมหรือเปลี่ยนฟิลเตอร์
4. กด **📄 PDF** ตั้งชื่อไฟล์ แล้วกด **สร้าง PDF** ตามด้วย **บันทึก / แชร์ไฟล์**
5. เลือก **บันทึกไปยังแอปไฟล์** เพื่อเก็บในเครื่อง

## เอาแอปขึ้นเว็บ (GitHub Pages ฟรี)
กล้องบน iPhone ใช้ได้เฉพาะเว็บที่เป็น HTTPS จึงต้องเอาไฟล์ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน github.com เช่นชื่อ `scanner`
2. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (`index.html`, `app.js`, `app.css`, `scan.js`, `pdf.js`, `sw.js`, `manifest.webmanifest` และโฟลเดอร์ `icons`)
3. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → branch `main` / `(root)` แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/scanner/`

### อัปเดตแอปในภายหลัง
เมื่อแก้ไฟล์ใดแล้ว ให้เปลี่ยน `VERSION` ใน `sw.js` ด้วย เช่นจาก `v1` เป็น `v2`
จากนั้นเปิดแอปตอนต่อเน็ต 1–2 ครั้ง มือถือจะโหลดเวอร์ชันใหม่มาเก็บไว้เอง

## ไฟล์ในโปรเจค
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอของแอป |
| `app.css` | หน้าตาแอป (รองรับโหมดมืด) |
| `app.js` | ควบคุมหน้าจอและบันทึกงานในเครื่อง (IndexedDB) |
| `scan.js` | หาขอบเอกสาร ดัดภาพให้ตรง และฟิลเตอร์ |
| `pdf.js` | สร้างไฟล์ PDF (เขียนเอง ไม่ใช้ไลบรารีภายนอก) |
| `sw.js` | เก็บไฟล์แอปไว้ในเครื่องเพื่อใช้งานออฟไลน์ |
